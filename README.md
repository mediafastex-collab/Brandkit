# Fastex Media Brand Kit

Brand voice, tone, logo, colour, typography, social media, ad and marketing guidelines for [Fastex Media](https://www.fastexmedia.com), with downloadable logos.

- **Live page:** https://mediafastex-collab.github.io/Brandkit/
- `assets/logos/` vector logos (SVG)
- `assets/original/` logo artwork as supplied
- `BRANDKIT_PROMPT.md` the master prompt used to build the kit
- `tools/` source for the page; run `python3 tools/build_logos.py` to rebuild `index.html`
